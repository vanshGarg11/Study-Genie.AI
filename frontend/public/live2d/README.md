# StudyGenie Live2D Assets

Put Live2D teacher avatar models in this folder.

Recommended app path:

```text
frontend/public/live2d/teacher/teacher.model3.json
```

Runtime URL:

```text
/live2d/teacher/teacher.model3.json
```

Important: Live2D models are not a single file. Keep the full exported/downloaded model folder together, including `.model3.json`, `.moc3`, textures, motions, physics, pose, and expression files.
